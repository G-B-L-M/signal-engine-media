# signal-engine · medya

Bu depo yalnızca **yayınlanan sosyal medya dosyalarını** barındırır (carousel PNG'leri
ve reel MP4'leri). Instagram Graph API dosya yüklemesi kabul etmiyor — medyayı public
bir HTTPS adresinden kendi çekiyor, bu depo o adresi sağlıyor.

Motor, brief arşivi ve analizler ayrı ve **private** depodadır (`signal-engine`).
